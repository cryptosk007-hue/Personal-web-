# Saood Khan — Personal Portfolio

A responsive, professional-light portfolio website for **Saood Khan**, AI & Web Developer.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, colors, and visual styling
- `script.js` — mobile navigation, active section link, and current year

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Open your repository: https://github.com/cryptosk007-hue/Personal-web
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder (not the ZIP file alone).
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then click **Save**.
8. Wait for GitHub Pages to publish. The site URL will appear in the Pages section.

## Personalize before publishing
- In `index.html`, update the email and WhatsApp contact cards with your real details.
- Replace the sample project-area cards with real project names, descriptions, screenshots, and links when ready.
- Add your own profile photo if you want one; the current hero artwork is CSS illustration and does not use a stock portrait.
- Update the social links as needed.

## Notes
- The Google Fonts stylesheet requires an internet connection; system sans-serif fonts will be used if it cannot load.
- This is a static website. It does not require Firebase, a server, or environment variables.
